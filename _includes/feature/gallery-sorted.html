Default is "image" (optional) - container-styles = adds css classes to allow you to style the container in which the gallery appears, e.g. "w-75 mx-auto" - item-styles = adds css classes to allow you to style the container in which the individual items appears, e.g. "card py-3" - "image-size" - will adjust the size of the images used in the gallery, options: original, small, thumb.
